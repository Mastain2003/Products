# Company Product Catalog v2

A parent product groups related variants, but **each variant is a separate catalog product**.

Each variant has its own unique ID, SKU, title, images, price, sale price, availability, condition, attributes and specifications.

The catalog displays every variant separately. The detail page for each variant includes a Related variants section linking to its siblings.

Replace image paths in `products.js` with your real images.

For public deployment, upload this folder to GitHub Pages, Netlify, Cloudflare Pages or Vercel.
